# Arctic Fisher

A 3‑D arctic fishing adventure game built with **Next.js**, **React‑Three‑Fiber**, and **Zustand** for state management.

## Features

- Dynamic start menu, game scene, and preview for browsers without WebGL support.
- Rich gameplay: boat upgrades, fishing tools, jobs, treasure hunting, combat encounters, daily challenges, and a skill system.
- Persisted save slots with auto‑save and manual slot management.
- Extensible architecture allowing new boats, fish species, weather patterns, and multiplayer modes.

## Development

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Lint and format
npm run lint
npm run format
```
